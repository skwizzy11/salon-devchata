# Девчата — Ленинский 168, кабинет 320

Одностраничник для студии маникюра и педикюра «Девчата» (Санкт-Петербург,
Московский район). Это **замена существующему сайту**, а не первый сайт: у студии
уже есть `devchatanails.clients.site` — шаблон Яндекс Бизнеса на общем поддомене.

Статика без сборки и фреймворков: `index.html` с инлайновым `<style>`, самохостинг
шрифта, изображения в `img/`. Открыть можно двойным кликом по `index.html`.

```
index.html          вся вёрстка + инлайн CSS + JSON-LD
fonts.css           Onest, вариативный 400–800, 4 сабсета
fonts/*.woff2       cyrillic, cyrillic-ext, latin, latin-ext
img/                фото студии, работы, портреты мастеров
favicon.svg/.png    табличка «320» — номер кабинета
apple-touch-icon.png
og.jpg              1200×630
robots.txt, 404.html
```

## Откуда взяты факты

Ни одного придуманного числа. Всё перепроверено 14.09.2026 по открытому API DIKIDI
(без ключа) прямо перед вёрсткой.

| Что | Источник |
|---|---|
| Прайс: 37 позиций, цены и длительность в минутах | `GET /api/v1/companies/537441/services` |
| Рейтинг 4,89 · 353 оценки · 94 отзыва с текстом | `…/reviews/stats` |
| Тексты отзывов, имена, даты, мастера | `…/reviews` |
| Портфолио, 37 работ | `…/examples` |
| Мастера: должность, рейтинг, число отзывов, тексты о себе | `…/masters` |
| Адрес, координаты, график, телефон, VK/TG, описание, фото интерьера | `…/companies/537441` |
| Яндекс.Карты: 5,0 · 168 отзывов | карточка студии |

**Прайс и JSON-LD генерируются скриптом из ответа API** (`_work/build.py`), а не
переписываются руками — поэтому 37 цен и 37 минут в разметке гарантированно совпадают
с источником. Папка `_work/` — рабочая, в поставку не входит.

### Что изменилось с момента брифа

- **У Евгении появился рейтинг: 4,81 при 50 отзывах.** В исходном фактлисте стояло
  «—». На сайте живая цифра.
- Остальные факты сошлись с фактлистом дословно, включая цитаты отзывов.

### Чего на сайте НЕТ и почему

Не подтверждено — значит, не написано. Владелица увидит.

- Год открытия студии. Нигде не нашёлся, «с 20хх года» не написано.
- Юрлицо, ИП, ИНН.
- Имя владелицы.
- Администратор Наталья — фигурирует в одном отзыве, как штатная позиция не заявлена.
- **Мастер Мария** — у неё шесть отзывов, последний от 15 июля 2026, но в списке
  доступных для записи её нет. Ни карточки, ни упоминаний на сайте: отзыв, где её
  хвалят, заменён на отзыв о Анастасии. Иначе гостья прочитала бы «Мария милейший
  мастер», пришла за ней и не нашла. Вернуть легко, если Мария работает.
- Стаж мастеров — кроме Анжелики, у неё «более 4 лет» её собственными словами.
- «100% довольных», «все в восторге» и подобное. Из 353 оценок есть одна двойка и
  четыре тройки — обещать безупречность нельзя. Но и печатать разбивку по звёздам
  на продающей странице незачем: стоит 4,89 из 5, это само по себе не пятёрка,
  додумывать читателю нечего.

## Что нужно от клиента

1. **Домен.** Своего нет. Сейчас в `canonical`, `og:url` и JSON-LD стоит заглушка
   `https://devchata.example/` — заменить перед публикацией (поиском по файлам,
   встречается в `index.html` и `robots.txt`).
2. **Как попасть в БЦ «Энергия».** Нужен пропуск? Турникет? Домофон? На каком этаже
   лифт? Это первый вопрос гостьи, которая едет впервые, и его нет ни в одном
   источнике — поэтому на сайте сейчас только «БЦ «Энергия», офис 320».
3. **Оригиналы фотографий.** Всё, что удалось достать, — 1024 px по длинной стороне
   (это максимум, который отдаёт DIKIDI). Для первого экрана на большом мониторе
   этого впритык: снимок слегка мягкий. Карточка Яндекса (~270 фото в большем
   разрешении) из сети, где велась работа, не открывалась — соединение рвалось.
   Если у студии есть исходники с телефона, герой станет заметно резче.
4. **Работает ли сейчас мастер Мария.** Если да — вернуть её отзыв и добавить
   карточку; если нет — оставить как есть.
5. Подтвердить, что **скидка 300 ₽** на первый визит с гель-лаком ещё действует.

## Решения, которые стоит знать

**Палитра — из их же кабинета, а не из шаблона.** Тёплый белый стен `#F4F1EC`,
чернила `#2B2220`, пудра кресел `#EADCD5`. Каждая пара проверена замером контраста:
основной текст 13,78:1, приглушённый 5,79:1, текст на пудре 11,61:1. Шалфей со стены
кабинета `#A1ABA1` даёт всего 2,1:1 — поэтому он **только декор, текстом им не пишем**.

**Конфликт фуксии решён осознанно.** Физическая студия — приглушённая пудра
(S 8–37), а в виджете записи DIKIDI владелица выбрала ядовитую фуксию
(`#fc3ca9`, `#d83f83`). Страница живёт в пудре; единственное насыщенное пятно —
сами работы на фото. Фуксия допущена ровно в одном месте: кнопка записи, чтобы
переход на виджет DIKIDI не выглядел обрывом. Её оттенок затемнён с `#d83f83` до
`#CE3178` — исходный давал с белым текстом 4,24:1 и не проходил по контрасту,
затемнённый даёт 4,84:1.

**Жанр — приёмная карта, а не бутик.** У бизнеса есть фактура, которой нет у
конкурентов: кабинет 320 в бизнес-центре, работа до десяти вечера каждый день,
прайс с точностью до минуты, пять мастеров с написанными от руки текстами. Отсюда
фирменная деталь — **числовая рейка**: правая колонка с `tabular-nums`, сквозная
через прайс, карточки мастеров и часы работы. Страница читается как расписание.
Штамп «кремовый фон + контрастный сериф + терракота» сознательно не взят.

**Заголовок — её собственная фраза.** «Поддержим беседу или помолчим» взято дословно
из описания студии. Эту строку физически нельзя вставить конкуренту, и она сразу
задаёт тон: сюда идут не только за покрытием. Первый вариант открывался номером
кабинета («Кабинет 320.») — точный факт, но на первом экране он читался как табличка
на двери, а не как приглашение. Номер переехал в подзаголовок, где работает
навигацией: «Ежедневно с 10:00 до 22:00, кабинет 320 в БЦ «Энергия»». Что это за
бизнес, называет подзаголовок, а не заголовок, — для холодного трафика из поиска это
закрывают `<title>`, description и пилюли с фактами.

**Мастера — ростер, а не «наша команда».** Пять строк списка, у каждой свой текст
о себе, своя должность, свой рейтинг и своё число отзывов. Это лучший актив страницы.

**Светлый скрим в герое.** Фотографии студии светлые и низкоконтрастные — тёмный
скрим по ним даёт грязь. Приём перевёрнут: скрим светлый, текст чернильный.

**Описания услуг подрезаны.** В API у 12 позиций описания на 500+ знаков рекламного
текста — они ломали читаемость таблицы. Показываются только короткие пометки
(≤110 знаков), которые реально нужны: «снятие включено в стоимость», «маникюр в
стоимость не входит». Цены и минуты — все 37, целиком.

## Движение

Взято только то, что несёт смысл:

1. **Раскрытие групп прайса** — единственное место, где анимация функциональна:
   это смена состояния. `::details-content`, высота + прозрачность, 240 мс.
2. **Отклик кнопок** — `scale(.98)`, 140 мс.
3. **Состояние шапки** — прозрачная над героем, плотная на скролле, 200 мс.
4. **Появление секций** — fade + 8 px, 500 мс, стаггер 60 мс.

Отклонено и почему:

- **Стаггер по карточкам мастеров** — это текст, который читают; задержка мешает.
- **Подъём фотографий работ по ховеру** — украшательство, ничего не сообщает.
- **Анимация появления первого экрана** — кто, что, где и телефон должны читаться
  мгновенно, анимация их задерживает.
- **Параллакс, карусели, счётчики** — запрещены брифом и не нужны.

### Защита от «пол-страницы невидимо навсегда»

Это главная мина при появлении секций по скроллу, и здесь она обезврежена тремя
независимыми слоями:

1. Класс `.reveal-on`, который прячет элементы, выставляется скриптом **только
   после** успешного создания `IntersectionObserver` — не в `<head>`.
2. Всё, что уже находится в кадре на момент запуска, показывается **сразу и
   синхронно**, без ожидания наблюдателя. Без этого заход по якорю (`#price`)
   оставлял бы пустой экран.
3. Если за 3 секунды не раскрылось вообще ничего — страховка показывает страницу
   целиком. Любое исключение на любом шаге делает то же самое.

Проверено замером: при прокрутке к каждой секции (`#masters`, `#price`,
`#reviews`, `#contacts`) скрытых элементов в кадре — ноль.

`prefers-reduced-motion` уважается. Добавлен и `@media print`: без него страница
уходила бы в PDF с пустыми полосами, потому что до срабатывания наблюдателя
секции скрыты.

## Чем это лучше `devchatanails.clients.site`

| | Нынешний сайт | Этот |
|---|---|---|
| Вес кода | **2 454 КБ** HTML+JS+CSS до единой картинки (25 JS-файлов, 9 CSS) | 78 КБ HTML, 86 КБ шрифтов, 0 JS-библиотек |
| Домен | чужой общий поддомен `*.clients.site` | свой (нужно купить) |
| Прайс | «каталог», который рисует JS | все 37 позиций в HTML, видны поиску без исполнения скриптов |
| Разметка для поиска | шаблонная | `NailSalon` с `aggregateRating`, `openingHoursSpecification`, `geo`, `employee` на пятерых и `hasOfferCatalog` на 37 реальных цен |

| Мастера | нет | пять, с их словами и их рейтингами |

## Проверено

- Ширины 320 / 360 / 390 / 414 / 768 / 960 / 1280 / 1440 — горизонтального скролла нет.
- Контраст каждой пары цветов измерен, минимум 4,84:1.
- Кириллица и знак ₽ (U+20BD, живёт в сабсете latin-ext) не выпадают в системный шрифт.
- Тап-таргеты ≥ 44 px, `:focus-visible` виден и на акцентной полосе не сливается с фоном.
- Страница работает с отключённым JS: прайс раскрыт, шапка статична, ничего не скрыто.
- Прокрутка к каждой секции: скрытых элементов в кадре нет.
- Печать (`@media print`): страница уходит в PDF целиком, с раскрытым прайсом.

### Что поправлено по итогам код-ревью

- `role="img"` у звёзд в отзывах — без него `aria-label` игнорируется и скринридер
  читал пять «чёрных звёзд».
- Рейтинги мастеров получили скрытую подпись «Рейтинг: 4,96 из 5, отзывов: 92» —
  сама звезда рисуется через `::before`, а генерируемый контент озвучивается ненадёжно.
- Финальная CTA-полоса перенесена внутрь `<main>`: она лежала вне landmark, и
  навигация по ориентирам пропускала главный блок с телефоном.
- `<main>` получил `tabindex="-1"`, иначе ссылка «К содержанию» в Safari не
  переносила фокус.
- Цитата на фотополосе переведена в `<figure><blockquote>` — как в отзывах.
- Внешние ссылки открываются в новой вкладке: `rel="noopener"` без `target`
  ничего не делал, а уход на DIKIDI закрывал бы сайт.
- Ниже 900 px шапка перестала быть фиксированной. Навигация там скрыта, и
  закреплённая полоса только съедала высоту экрана; телефон в шапке возвращён.
- Пятая работа больше не прячется на мобильном — лид обещает пять, показывать
  надо пять.
